OFFLINE AI PROJECT

OFFLINE GOOGLE - MUSKAN AI

Build a personal offline AI assistant using Python, Ollama, Qwen 2.5 3B, Vosk speech recognition and ESP32. Ask questions in English or Hindi, receive spoken answers, and interact with the assistant using an ESP32 push button and OLED display.

Explore Project

PROJECT OVERVIEW

About This Project

OFFLINE GOOGLE is a local AI assistant project named MUSKAN. It uses a Windows computer as its AI processing system and an ESP32 development board as its hardware interface.

The Python application communicates with Ollama running locally on the computer. The Qwen 2.5 3B model generates answers without requiring a cloud AI API.

Vosk provides offline English and Hindi speech recognition. Python speech libraries handle microphone input and spoken responses.

The ESP32 connects to the computer through USB serial communication. It provides a push button for interaction and an SSD1306 OLED display for showing information.

WHAT IT CAN DO

Project Features

Local AI Brain

Generate answers using Ollama and the locally installed Qwen 2.5 3B model.

English Voice Recognition

Recognize spoken English using the Vosk English speech model.

Hindi Voice Recognition

Recognize spoken Hindi using the Vosk Hindi speech model.

Voice Responses

Speak generated answers using the Python text-to-speech system.

ESP32 Communication

Exchange commands and display information between the computer and ESP32 through USB serial.

OLED Display

Show assistant status and information on an SSD1306 OLED display.

Push Button

Use a physical button connected to the ESP32 to interact with the assistant.

Local Processing

Process AI questions locally after the required software and models are installed.

ESP32 Wiring Connections

Component Component Pin ESP32 Connection
OLED Display SDA GPIO 4
OLED Display SCL GPIO 15
OLED Display VCC Suitable supply voltage for the display module
OLED Display GND GND
Push Button One terminal GPIO 27
Push Button Other terminal GND
ESP32 USB Computer USB port
The push button uses the ESP32 INPUT_PULLUP configuration. The OLED uses I2C communication at address 0x3C. Check the voltage requirements of your OLED module before connecting its power pins.

INSTALLATION GUIDE

How to Set Up MUSKAN AI

  1. Install Python 3.11 on your Windows computer.
  2. Install Ollama on the computer.
  3. Open Command Prompt and download the Qwen model using: 
    ollama pull qwen2.5:3b
  4. Install the Python dependencies using the supplied requirements.txt file.
  5. Create a folder named models inside the Python project folder.
  6. Download the Vosk English model: vosk-model-small-en-us-0.15.
  7. Download the Vosk Hindi model: vosk-model-small-hi-0.22.
  8. Extract both model folders inside the models folder.
  9. Connect the ESP32 to the computer using a USB data cable.
  10. Open muskan_hardware.ino in Arduino IDE.
  11. Install the required Adafruit display libraries and upload the firmware to the ESP32.
  12. Check the serial port used by the ESP32 in the Python application configuration.
  13. Start the Ollama service and run the Python application.
The two Vosk speech models are not included in the GitHub source downloads because they are large files. They must be downloaded and extracted separately. The Qwen model is installed through Ollama.

MODEL INSTALLATION

Required Folder Structure

After downloading and extracting the two Vosk models, your Python project should have this folder structure: 

MUSKAN_HARDWARE/
│
├── main_hardware.py
├── local_ai.py
├── voice.py
├── requirements.txt
│
└── models/
    │
    ├── vosk-model-small-en-us-0.15/
    │
    └── vosk-model-small-hi-0.22/

Keep the model folder names exactly as shown because voice.py uses these names to locate the models.

HOW IT WORKS

Step-by-Step Operation

  1. Connect the ESP32 to the Windows computer.
  2. The ESP32 initializes the OLED display and push button.
  3. Start the Python MUSKAN application.
  4. The application loads the English and Hindi Vosk models.
  5. Ask a question using the supported text or voice interaction.
  6. The speech recognition system processes microphone input.
  7. The recognized question is sent to the local Qwen AI model through Ollama.
  8. The AI generates an answer locally.
  9. The Python application speaks the answer using pyttsx3.
  10. The computer communicates with the ESP32 to display information on the OLED.

IMPORTANT INFORMATION

Operating Notes

  • Use a USB data cable that supports serial communication.
  • Check the correct ESP32 COM port before running the application.
  • Close other applications that may be using the ESP32 serial port.
  • Ensure both Vosk model folders are extracted correctly.
  • Make sure Ollama is running and qwen2.5:3b is installed.
  • Connect a working microphone and speaker or headphones.
  • Check the OLED wiring and power supply before switching on.
  • Keep the original Python files and folder names together.
Offline operation requires the software, AI model, speech models and dependencies to be installed first. Internet may be needed for initial downloads and updates.
