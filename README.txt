VJAYA ROBOTICS WEBSITE — STARTER PROJECT

HOW TO OPEN
1. Extract the Vjaya.zip file.
2. Open the extracted Vjaya folder in Visual Studio Code:
   VS Code > File > Open Folder > select Vjaya.
3. Open index.html and use the Live Server extension (if installed), or double-click index.html to preview it in your browser.

PROJECT FILES
index.html       Main website structure
css/style.css    Website design and responsive layout
js/products.js   Sample robotics products
js/cart.js       Shopping cart logic
js/app.js        Page rendering and event handling

IMPORTANT
- This is a front-end starter. Sample product names and prices are placeholders.
- Cart works in the browser, but orders are not saved to a server.
- Online payments, customer accounts, inventory and admin tools are not connected yet.
- Replace sample products with your own actual product details before publishing.
