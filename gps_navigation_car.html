ARDUINO ROBOTICS PROJECT

Arduino UNO

GPS NAVIGATION CAR

Build an autonomous robot car that navigates toward destination coordinates received from a smartphone through Bluetooth. The system uses GPS positioning, a digital compass, motor control and ultrasonic obstacle detection.

Explore Source Code

PROJECT OVERVIEW

About This Project

The GPS Navigation Car is based on an Arduino UNO. A smartphone sends destination latitude and longitude through an HC-05 Bluetooth module.

The GPS module provides the current location. The QMC5883L compass measures the car's heading. The navigation module calculates the direction toward the destination and controls the motors through an L298N motor driver.

An HC-SR04 ultrasonic sensor checks for obstacles in front of the car and stops the motors when an obstacle is detected within the configured distance.

PROJECT FEATURES

Main Features

GPS Positioning

Reads the car's latitude and longitude using the GPS module.

Phone Destination

Receives destination coordinates from a smartphone over Bluetooth.

Compass Direction

Uses the QMC5883L compass to determine the current heading.

Obstacle Detection

Uses an ultrasonic sensor to stop the car when an obstacle is detected nearby.

Automatic Motor Control

Controls forward, backward, left, right and stop movements using the L298N.

Destination Arrival

Stops navigation when the GPS distance to the destination is 5 metres or less.

HOW IT WORKS

Working Principle

  1. The Arduino initializes the motors, GPS, compass, Bluetooth and obstacle sensor.
  2. The phone sends a destination using the Bluetooth command format: DEST,latitude,longitude
  3. The GPS module continuously updates the current geographical position.
  4. The navigation module calculates the distance and bearing toward the destination.
  5. The compass measures the current heading. The controller compares it with the target bearing.
  6. The car makes short turning or forward motor movements according to the heading error.
  7. The ultrasonic sensor checks for obstacles. The car stops when the measured distance is below the configured obstacle threshold.
  8. The car stops and sends a Bluetooth message when it reaches the configured arrival distance.

SAFETY AND TESTING

Important Notes

  • Test the motors with the wheels lifted before allowing the car to move on the ground.
  • Test GPS reception outdoors with a clear view of the sky.
  • Calibrate the compass away from motors, magnets and other magnetic interference.
  • Check the motor direction and sensor readings before autonomous operation.
  • The ultrasonic sensor only checks the area in front of its mounting position.
  • GPS navigation is not precise enough for collision-free operation around people, roads or moving vehicles. Supervise all tests.
This is an educational robotics prototype. The supplied code uses short motor movement pulses; it does not provide map-based route planning or certified autonomous vehicle safety.
