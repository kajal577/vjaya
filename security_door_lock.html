Smart Security Door Lock

Build an ESP32-based smart door lock using an SG90 servo motor, vibration detection, WiFi web control, browser voice commands and Telegram emergency notifications.

Explore Project

PROJECT OVERVIEW

About This Project

This project uses an ESP32 development board to control a door-lock mechanism using an SG90 servo motor. The system provides a web-based interface for locking and unlocking the door.

It also supports browser-based voice commands. A vibration sensor monitors disturbances and can trigger an emergency notification through a Telegram bot.

ESP32 Wiring Connections

Component Component Pin ESP32 Pin
SG90 Servo Signal GPIO 13
SG90 Servo VCC External regulated 5V
SG90 Servo GND Common GND
Green LED Positive through resistor GPIO 14
Red LED Positive through resistor GPIO 12
Vibration Sensor Digital Output GPIO 15
Power the SG90 using a suitable regulated 5V supply. Connect the external supply GND to ESP32 GND. Do not power the servo from the ESP32 3.3V pin. Check your vibration sensor module's voltage requirements.

SOFTWARE REQUIREMENTS

Arduino IDE Libraries

  • WiFi.h — ESP32 WiFi connectivity
  • WebServer.h — ESP32 web server
  • ESP32Servo.h — Servo motor control
  • WiFiClientSecure.h — Secure network client interface
  • HTTPClient.h — HTTP communication

WiFi.h, WebServer.h, WiFiClientSecure.h and HTTPClient.h are provided by the ESP32 Arduino platform. Install the ESP32Servo library separately.

HOW IT WORKS

Step-by-Step Operation

  1. Power on the ESP32 development board.
  2. The ESP32 connects to the configured WiFi network.
  3. The ESP32 starts its web server on port 80.
  4. Open the smart lock webpage using a browser.
  5. Send a lock or unlock command through the web interface.
  6. The SG90 servo moves to the programmed position.
  7. The red and green LEDs indicate the lock command state.
  8. The vibration sensor monitors its digital output.
  9. When vibration alert conditions are met, the ESP32 attempts to send a Telegram notification.
  10. Supported browsers can also recognize voice commands.

IMPORTANT INFORMATION

Safety and Security Notes

  • The current web control endpoints do not require authentication. Use only on a trusted private network.
  • Do not expose the ESP32 web server directly to the public internet.
  • The sketch uses setInsecure() for Telegram HTTPS requests, which disables certificate verification.
  • Browser voice recognition support varies by browser.
  • The SG90 is intended for a small demonstration mechanism, not a heavy real door bolt.
  • This project is an educational prototype, not a certified home-security system.
