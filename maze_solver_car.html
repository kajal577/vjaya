MAZE SOLVER CAR

Build an autonomous robot car using Arduino UNO, an ultrasonic distance sensor, a servo motor and an L298N motor driver.

PROJECT OVERVIEW

About This Project

The Maze Solver Car is an autonomous robot that uses an ultrasonic sensor mounted on a servo motor to measure distances in different directions.

The Arduino UNO processes the distance measurements and controls the motors through an L298N motor driver. The navigation program prioritizes turning left, moving forward and turning right. When all three directions are blocked, it performs a reverse and turning sequence.

ROBOT CAPABILITIES

Project Features

Obstacle Detection

Measures distances using an ultrasonic sensor.

Servo Scanning

Scans the left, front and right directions.

Automatic Movement

Controls forward, backward, left and right movement.

Left-Priority Navigation

Checks the left direction first, followed by front and right.

Dead-End Response

Reverses and performs a programmed turn when blocked.

Modular Programming

Uses separate motor, sensor and navigation modules.

NAVIGATION LOGIC

How It Works

  1. The servo positions the ultrasonic sensor to the left.
  2. The sensor measures the left-side distance.
  3. The sensor scans forward and measures the front distance.
  4. The sensor scans right and measures the right distance.
  5. The Arduino checks whether each direction has more than 25 cm clearance.
  6. If the left path is open, the robot turns left.
  7. Otherwise, it checks the front and then the right.
  8. If all directions are blocked, the robot reverses and turns around.

This implementation uses distance thresholds and timed motor movements. Turning accuracy depends on the motors, battery, chassis and timing calibration. It does not map the maze or guarantee an optimal route.
