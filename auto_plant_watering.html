ESP32 IOT PROJECT

Automatic Plant Watering System

Build an intelligent automatic plant watering system using ESP32 and a soil moisture sensor. The system automatically detects dry soil and switches ON a water pump to provide water to the plant. When sufficient moisture is detected, the pump automatically switches OFF.

Explore Project

PROJECT OVERVIEW

About This Project

The Automatic Plant Watering System is designed to automatically water plants according to soil moisture levels.

An ESP32 reads the analog output of a soil moisture sensor. When the soil becomes dry, the ESP32 activates a relay module connected to a water pump.

Once the soil reaches the required moisture level, the ESP32 switches OFF the pump. This helps reduce unnecessary water usage and manual watering.

WHAT IT CAN DO

Project Features

Automatic Watering

Automatically waters plants when the soil becomes dry.

Soil Moisture Detection

Continuously measures soil moisture using a soil moisture sensor.

ESP32 Controller

Uses ESP32 to process sensor readings and control the watering system.

Automatic Pump Control

Controls a water pump through a relay module.

Water Saving

Avoids unnecessary watering by responding to soil moisture conditions.

HARDWARE REQUIREMENTS

Components Required

  • ESP32 Development Board
  • Capacitive Soil Moisture Sensor
  • 5V Relay Module
  • Mini DC Water Pump
  • Water Pipe / Tube
  • External Power Supply for Water Pump
  • Jumper Wires
  • Breadboard (Optional)
  • Plant Pot and Water Container
Use a suitable external power supply for the water pump. Never power the pump directly from an ESP32 GPIO pin. Keep the ESP32 and its connections protected from water.

SOFTWARE REQUIREMENTS

Software and Libraries

  • Arduino IDE
  • ESP32 Board Package
  • Arduino Core for ESP32
  • USB Data Cable
The basic automatic watering system does not require any external Arduino library. Sensor reading and relay control can be implemented using the ESP32 Arduino core.

HOW IT WORKS

Step-by-Step Operation

  1. The ESP32 initializes the soil moisture sensor and relay output pin.
  2. The soil moisture sensor measures the moisture level in the soil.
  3. The sensor sends an analog signal to the ESP32.
  4. The ESP32 compares the sensor reading with the configured dry-soil threshold.
  5. If the soil is dry, the ESP32 activates the relay and switches ON the water pump.
  6. Water is supplied to the plant through the pipe.
  7. When sufficient moisture is detected, the ESP32 switches OFF the water pump.

SENSOR / CONTROL LOGIC

Automatic Watering Logic

Soil Condition Water Pump Action
Soil is dry Turn ON pump
Soil moisture is increasing Continue watering until target is reached
Soil is sufficiently moist Turn OFF pump
Sensor reading is invalid Keep pump OFF as a safety response
Calibrate the moisture sensor in your own soil before setting the threshold. Sensor readings vary between sensors and soil conditions. Use separate ON and OFF thresholds to prevent rapid relay switching.

ESP32 PIN CONFIGURATION

Pin Connections

Component ESP32 Connection
Soil Sensor VCC 3.3V
Soil Sensor GND GND
Soil Sensor AO GPIO 34
Relay IN GPIO 26
Relay VCC Suitable relay supply
Relay GND GND
GPIO 34 is an input-only ADC pin. Use a sensor output that stays within the ESP32's permitted input voltage. Check relay module voltage and trigger compatibility. The pump power circuit must be separate from the ESP32 GPIO supply.

IMPORTANT INFORMATION

Setup and Safety Notes

  • Calibrate the soil moisture sensor before configuring the watering threshold.
  • Never connect the water pump directly to an ESP32 GPIO pin.
  • Use a suitable external power supply for the water pump.
  • Check the relay module's voltage rating and trigger compatibility before connecting it.
  • Keep the ESP32 board and electrical connections away from water.
  • Use a protected and properly insulated power connection.
  • Test the relay and pump separately before running the automatic watering system.
  • Add a maximum pump-running timeout to prevent continuous watering if the sensor fails.
