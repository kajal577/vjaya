ARDUINO ROBOTICS PROJECT

Bluetooth Robot Car

Build a wireless robot car using an Arduino UNO, HC-05 Bluetooth module and L298N motor driver. Control the robot from a Bluetooth-enabled phone by sending forward, backward, left, right and stop commands.

Explore Project

PROJECT OVERVIEW

About This Project

This Bluetooth Robot Car uses an Arduino UNO as its main controller. The HC-05 Bluetooth module receives commands from a phone and passes them to the Arduino.

The Arduino processes the received command and controls the L298N motor driver. The motor driver operates the two DC motors to move the robot in the selected direction.

The example firmware supports F, B, L, R and S commands. It also includes a command timeout so the motors stop if communication is interrupted.

WHAT IT CAN DO

Project Features

Wireless Control

Control the robot using a Bluetooth-enabled Android phone.

Forward Movement

Move both motors in the forward direction using a phone command.

Reverse Movement

Drive the robot backward when the backward command is received.

Turning Control

Turn left or right by controlling the direction of the motors.

Emergency Stop Command

Stop both motors when the stop command is received.

Communication Timeout

Stop the motors if no new Bluetooth command is received within the timeout.

HARDWARE REQUIREMENTS

Components Required

  • Arduino UNO
  • HC-05 Bluetooth module
  • L298N dual H-bridge motor driver
  • 2 DC geared motors
  • Robot chassis and wheels
  • Motor battery pack
  • Jumper wires
  • Bluetooth-enabled Android phone
The HC-05 RX pin is not 5V tolerant. Connect Arduino TX to HC-05 RX through a suitable voltage divider. Connect the grounds together.

SOFTWARE REQUIREMENTS

Software and Libraries

  • Arduino IDE
  • Arduino UNO board package
  • SoftwareSerial library (standard Arduino library)
  • Bluetooth terminal or robot controller app

The Arduino program is organized into separate files for the main sketch, configuration, motor control and Bluetooth communication.

HOW IT WORKS

Step-by-Step Operation

  1. Power the Arduino UNO, L298N motor driver and HC-05 Bluetooth module.
  2. Pair the phone with the HC-05 Bluetooth module.
  3. Open a Bluetooth controller application and connect to the HC-05.
  4. Send a movement command from the phone.
  5. The HC-05 receives the command and sends it to the Arduino through serial communication.
  6. The Arduino checks the received command.
  7. The motor module controls the L298N inputs to move the robot.
  8. When the stop command is received, both motors stop.
  9. If communication is lost, the timeout function stops the motors.

HARDWARE CONNECTIONS

Arduino Pin Connections

Component Component Pin Arduino Connection
L298N IN1 D8
L298N IN2 D9
L298N IN3 D10
L298N IN4 D11
HC-05 TXD D2 (Arduino RX)
HC-05 RXD D3 (Arduino TX through voltage divider)
HC-05 VCC / GND Suitable supply / Common GND
This example uses SoftwareSerial at 9600 baud. Keep the L298N ENA and ENB jumpers installed when using the driver's default full-speed operation. Verify your module's power requirements before wiring.

BLUETOOTH CONTROL

Example Bluetooth Commands

Command Robot Action
F Move forward
B Move backward
L Turn left
R Turn right
S Stop both motors

The example firmware accepts lowercase versions of the commands as well. Unknown commands cause the robot to stop.

IMPORTANT INFORMATION

Setup and Safety Notes

  • Use a suitable voltage divider between Arduino TX and HC-05 RX.
  • Verify the motor battery voltage and current requirements before connecting the L298N.
  • Connect Arduino, motor driver and Bluetooth module grounds together.
  • Test the robot with its wheels raised before running it on the floor.
  • The timeout is a software safety feature. It does not replace a physical emergency stop.
  • Disconnect power before changing wiring.
