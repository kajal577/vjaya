RASPBERRY PI ROBOTICS PROJECT

Gesture-Controlled Robotic Arm

Build an intelligent robotic arm using Raspberry Pi 5, a camera, servo motors and a PCA9685 servo driver. Control the robotic arm by moving your hand in front of the camera using computer vision and MediaPipe.

Explore Project

PROJECT OVERVIEW

About This Project

This Gesture-Controlled Robotic Arm uses Raspberry Pi 5 as its main controller. A camera captures the user's hand movements and MediaPipe detects 21 hand landmarks.

Python processes the detected hand coordinates and converts them into servo movement commands. The PCA9685 servo driver controls the robotic arm joints.

The system supports a 4-DOF or 5-DOF robotic arm. Hand movements control the base, shoulder, elbow and wrist, while finger gestures control the gripper.

WHAT IT CAN DO

Project Features

Hand Detection

Detect hand movements using a camera and MediaPipe computer vision.

Base Rotation

Move your hand left or right to rotate the robotic arm base.

Shoulder Movement

Move your hand up or down to control the shoulder joint.

Elbow Control

Use hand landmark distance to calculate elbow movement.

Wrist Control

Control wrist movement using detected hand coordinates.

Gesture Gripper

Open your hand to open the gripper and make a fist to close it.

HARDWARE REQUIREMENTS

Components Required

  • Raspberry Pi 5
  • USB Webcam or Raspberry Pi Camera
  • 4-DOF or 5-DOF Servo Robotic Arm
  • PCA9685 16-Channel Servo Driver
  • Suitable External Servo Power Supply
  • MicroSD Card
  • Raspberry Pi Power Supply
  • Jumper Wires
  • Monitor, Keyboard and Mouse
Use a separate suitable power supply for the servo motors. Do not power multiple servos directly from the Raspberry Pi 5. Connect all grounds together.

SOFTWARE REQUIREMENTS

Software and Libraries

  • Raspberry Pi OS 64-bit
  • Python 3
  • OpenCV
  • MediaPipe
  • Adafruit CircuitPython PCA9685
  • Adafruit CircuitPython Motor
  • Adafruit Blinka
  • I2C Interface

The Python program is divided into separate modules for camera capture, hand tracking, gesture processing, servo control and configuration.

HOW IT WORKS

Step-by-Step Operation

  1. Power on the Raspberry Pi 5.
  2. Connect the camera to the Raspberry Pi.
  3. Connect the PCA9685 servo driver using I2C.
  4. Connect the robotic arm servos to the assigned PCA9685 channels.
  5. Start the Python application.
  6. The camera captures your hand movements.
  7. MediaPipe detects 21 hand landmarks.
  8. Python converts hand coordinates into servo target angles.
  9. The PCA9685 controls the robotic arm servos.
  10. Finger gestures control the robotic gripper.

HARDWARE CONNECTIONS

Raspberry Pi 5 Pin Connections

Component Component Pin Raspberry Pi Connection
PCA9685 VCC 3.3V
PCA9685 GND GND
PCA9685 SDA GPIO 2 (Pin 3)
PCA9685 SCL GPIO 3 (Pin 5)
PCA9685 V+ External Servo Supply Positive
USB Camera USB Raspberry Pi USB Port
Servo Motors Signal PCA9685 Channels 0–4
PCA9685 VCC is the logic supply and connects to Raspberry Pi 3.3V. PCA9685 V+ is the separate servo power input. Never connect servo supply voltage to the Raspberry Pi 3.3V pin.

IMPORTANT INFORMATION

Setup and Safety Notes

  • Use a suitable external power supply for the servo motors.
  • Connect Raspberry Pi, PCA9685 and servo power grounds together.
  • Enable I2C before using the PCA9685.
  • Verify the PCA9685 I2C address.
  • Calibrate the servo angles before operating the robotic arm.
  • Keep fingers away from moving joints and the robotic gripper.
  • Keep a physical power switch available for the servo supply.
  • Disconnect power before changing wiring.
