ESP32 PROJECT

ESP32 WiFi Scanner & Setup Portal

Scan nearby WiFi networks, display network information on an OLED screen and configure your ESP32 through a mobile-friendly WiFi setup webpage.

Explore Project

PROJECT OVERVIEW

About This Project

This project uses an ESP32 development board to discover nearby wireless networks and show their information. It also provides a browser-based setup portal that lets a user select a WiFi network and enter its password.

After a successful connection, the ESP32 saves the WiFi credentials using its Preferences storage. On the next startup, it can attempt to reconnect automatically.

WHAT IT CAN DO

Project Features

WiFi Scanning

Discover nearby wireless networks.

Network Information

Display SSID, RSSI signal strength and channel.

OLED Display

Display up to six discovered networks.

Setup Access Point

Create a temporary WiFi network for configuration.

Web Configuration

Select a WiFi network and enter its password using a phone.

Save Credentials

Store WiFi credentials in ESP32 Preferences.

HARDWARE REQUIREMENTS

Components Required

  • ESP32 DevKit V1 development board
  • SSD1306 128×64 I2C OLED display
  • Jumper wires
  • USB data cable
  • Computer with Arduino IDE
  • Smartphone for WiFi setup

SOFTWARE REQUIREMENTS

Arduino IDE Libraries

  • WiFi.h — ESP32 WiFi functionality
  • WebServer.h — browser-based web server
  • Preferences.h — save WiFi credentials
  • Adafruit GFX Library
  • Adafruit SSD1306 Library

WiFi.h, WebServer.h and Preferences.h are provided by the ESP32 Arduino platform.

HOW IT WORKS

Step-by-Step Operation

  1. Power on the ESP32.
  2. Scan nearby WiFi networks.
  3. Display the discovered networks on the OLED.
  4. Attempt to connect using saved WiFi credentials.
  5. If connection fails, start the MUSKAN_SETUP access point.
  6. Connect your phone to the setup network.
  7. Open the setup webpage using the IP address shown in Serial Monitor.
  8. Select a network and enter its password.
  9. Connect and save the credentials.
