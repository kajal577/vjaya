ARDUINO ROBOTICS PROJECT

Object Avoidance Robot Car

Build an autonomous robot car that measures the distance to obstacles using an HC-SR04 ultrasonic sensor. When an obstacle is detected, the car stops, reverses, scans left and right with a servo-mounted sensor, and turns toward the clearer direction.

Explore Project

PROJECT OVERVIEW

About This Project

This project uses an Arduino UNO to control two DC motors through an L298N motor driver. The HC-SR04 sensor measures the distance in front of the robot. An SG90 servo rotates the sensor so the robot can compare the space on its left and right.

The supplied example uses a threshold distance and timed motor movements. Actual turning performance depends on the chassis, motor speed, battery voltage, sensor mounting and floor surface. Adjust the threshold and turn timing during testing.

WHAT IT CAN DO

Project Features

Ultrasonic Distance Measurement

Measure the distance in front of the car with the HC-SR04 sensor.

Obstacle Response

Stop and reverse when an obstacle is closer than the configured threshold.

Servo Scanning

Rotate the sensor to inspect the left and right directions.

Direction Selection

Compare the measured side distances and turn toward the more open direction.

Modular Firmware

Keep motor, ultrasonic sensor and servo-scanning code in separate source files.

HARDWARE REQUIREMENTS

Components Required

  • Arduino UNO
  • L298N dual H-bridge motor driver
  • HC-SR04 ultrasonic sensor
  • SG90 servo motor
  • 2 DC geared motors and wheels
  • Robot chassis
  • Motor battery pack and suitable regulated servo supply
  • Jumper wires
Use a suitable battery for the motors and driver. Connect the Arduino, driver and sensor grounds together. Disconnect power before changing wiring.

SOFTWARE REQUIREMENTS

Software and Libraries

  • Arduino IDE
  • Arduino UNO board package
  • Servo library (standard Arduino library)

The project is an Arduino sketch made of a main .ino file and supporting .h/.cpp modules. Open the .ino file from the same project folder in Arduino IDE.

HOW IT WORKS

Step-by-Step Operation

  1. The Arduino initializes the motor pins, ultrasonic sensor and servo scanner.
  2. The servo positions the ultrasonic sensor toward the front.
  3. The HC-SR04 measures the distance to the nearest object in front.
  4. If the path is clear, the motors drive the car forward.
  5. If an obstacle is detected, the robot stops and reverses briefly.
  6. The servo scans the left and right sides and records their distances.
  7. The robot turns toward the side with more available space, then resumes checking the front.

CONTROL / SENSOR LOGIC

Obstacle Avoidance Logic

Input / Condition Robot Action
Front distance above the obstacle threshold Continue forward
Front distance at or below the threshold Stop, then reverse briefly
Left side has more clearance than right Turn left
Right side has more clearance than left Turn right
Both directions have limited clearance Reverse again or stop for safety
The example program uses timed turns, not wheel encoders. It is a basic behavior and may need calibration for your chassis and environment.

IMPORTANT INFORMATION

Setup and Safety Notes

  • Test the car with its wheels raised before running it on the floor.
  • Do not power the servo from an Arduino pin. Use a suitable regulated supply if the servo draws more current than the board can provide; connect grounds together.
  • Use a suitable motor battery and do not exceed the L298N or motor voltage/current ratings.
  • The ultrasonic sensor can miss soft, angled, narrow or distant objects. Keep the robot supervised.
  • Disconnect power before rewiring.
