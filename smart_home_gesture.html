SMART HOME AUTOMATION

Smart Home Gesture Control

Control home appliances using hand gestures detected through a computer webcam. This project combines Python, OpenCV, MediaPipe, Arduino UNO and HC-05 Bluetooth communication to control a light and fan without using physical switches.

Explore Project

PROJECT OVERVIEW

About This Project

Smart Home Gesture Control is a hand-gesture-based home automation project. It allows the user to control a light and a fan using different hand gestures in front of a computer webcam.

Python handles webcam access and hand gesture detection using OpenCV and MediaPipe.

After detecting a gesture, the Python application sends the corresponding command through Bluetooth using an HC-05 module.

The Arduino UNO receives the Bluetooth command and controls the light and fan through relay modules.

HARDWARE CONNECTION

Arduino UNO and HC-05 Wiring

Component Component Pin Arduino UNO Connection
HC-05 TXD D3 (Arduino SoftwareSerial RX)
HC-05 RXD D4 (Arduino SoftwareSerial TX)
HC-05 VCC Suitable module supply
HC-05 GND Arduino GND
Light Relay IN1 D7
Fan Relay IN2 D8
Relay Module VCC Suitable module supply
Relay Module GND Arduino GND
Computer USB Arduino UNO USB connection
Webcam USB / Camera Computer
The computer webcam connects to the computer. Python communicates with Arduino UNO through the HC-05 Bluetooth module. The HC-05 TXD connects to Arduino D3, and HC-05 RXD connects to Arduino D4. Check the HC-05 logic-level requirements before connecting its RXD pin. Use suitable relay contacts and electrical protection for the appliances.

HOW IT WORKS

Step-by-Step Operation

  1. Connect the HC-05 Bluetooth module to Arduino UNO.
  2. Connect the relay module to Arduino UNO.
  3. Connect the light and fan to their respective relay output connections.
  4. Upload the Arduino firmware.
  5. Pair the computer with the HC-05 Bluetooth module.
  6. Connect the computer webcam.
  7. Start the Python Smart Home Gesture application.
  8. Python captures live webcam frames using OpenCV.
  9. MediaPipe processes the frames and detects hand gestures.
  10. The Python application checks gesture stability.
  11. The corresponding command is sent through HC-05 Bluetooth.
  12. Arduino UNO receives the command and controls the relays.
  13. The light and fan respond according to the detected gesture.

HAND GESTURE CONTROL

Hand Gesture Commands

Each hand gesture performs a specific home automation operation. The webcam detects the gesture, and the computer sends the corresponding Bluetooth command to Arduino UNO.

Hand Gesture Action
1 Finger Raised Light ON
2 Fingers Raised Light OFF
3 Fingers Raised Fan ON
4 Fingers Raised Fan OFF
Open Palm Light ON + Fan ON
Closed Fist All OFF
The Python application detects and stabilizes the hand gesture before sending the corresponding command to Arduino UNO.

IMPORTANT INFORMATION

Safety and Operating Notes

  • Check all Arduino and relay connections before powering the circuit.
  • Use a suitable power supply for the relay module.
  • Check the HC-05 module's voltage and logic-level requirements before connecting it.
  • Use correctly rated relay contacts for the connected appliances.
  • Disconnect power before changing any wiring.
  • Keep mains-voltage connections insulated and enclosed in a suitable electrical enclosure.
  • Do not touch exposed mains wiring or relay terminals.
  • Test the gesture detection and Bluetooth communication before connecting actual appliances.
